# Demonstração — SOS Abstinência Emocional

Esta página é uma **demonstração não oficial** de layout, preparada para uma proposta no 99Freelas.

Não é o site oficial do produto SOS Abstinência Emocional e não está associada à autora nem à cliente do projeto. Os textos e as imagens são placeholders e só serão substituídos pelo material da cliente se a proposta for aceita.

A página está configurada para não ser indexada (`meta noindex` e `robots.txt` com `Disallow: /`). Há um aviso fixo no topo deixando claro que se trata de uma demonstração. Os botões de compra apontam apenas para a âncora `#checkout` e não abrem um checkout real.

As fontes Fraunces e Nunito estão incluídas localmente, sob a licença SIL Open Font License (OFL). Os textos da licença estão em `fonts/OFL-Fraunces.txt` e `fonts/OFL-Nunito.txt`.
